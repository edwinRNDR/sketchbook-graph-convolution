# sketchbook-graph-convolution

A research and experimentation sketchbook project focused on implementing and exploring graph signal processing (GSP)
concepts and algorithms. This project provides tools and implementations for processing signals defined on irregular
graph structures.

## Overview

This project implements fundamental graph signal processing operations including:

- Graph construction and manipulation
- Graph convolution operations

## Key Features

- Graph data structure implementation
- Adjacency and Laplacian matrix computations
- Graph signal filtering operations
- Visualization tools for graph signals
